# FoxShell

SSH 连接管理工具：多标签终端 · 分屏 · SFTP · 资源监控 · 批量执行 · 端口转发 · 跳板机。

## 下载

到 [Releases](https://github.com/The7wa/foxshell/releases) 下载压缩包，解压后运行 `FoxShell.exe` 即可，免安装。

## 功能

- **连接管理**：文件夹分组、搜索、克隆、导入/导出；密码 / 私钥登录；支持跳板机
- **终端**：多标签 + 左右/上下分屏 + 复制终端；背景/字体/光标样式自定义；主题一键切换；Ctrl+F 搜索；日志导出
- **SFTP**：浏览、上传、下载（支持文件夹）、重命名、删除，带进度条
- **资源监控**：CPU / 内存 / 网络 / 磁盘 / 负载 / 运行时长，实时刷新
- **批量执行**：勾选多台服务器，一条命令同步执行
- **端口转发**：本地端口 → 远程目标，一键启停

## 说明

- 连接配置保存在本地 `%APPDATA%/foxshell/connections.json`，口令使用随机主密钥加密，主密钥由系统安全存储（Windows DPAPI）保护，两者分离存储
- 程序不含遥测、自动更新或云服务；页面层禁止外部网络请求，除你主动发起的 SSH / SFTP 连接外不会自动联网
- 跳板机支持任意多条，按列表顺序连接，不限制数量
- 首次连接会显示服务器 SHA256 指纹并要求确认；确认后保存在本机 `known_hosts.json`，指纹变化会被阻止
- 资源监控依赖 Linux 的 /proc，连接其他系统时监控栏提示不可用，终端与 SFTP 不受影响

## 安全说明

- 请勿分享或提交 `connections.json`、`foxshell.key` 和导出文件；本仓库源码中不包含固定口令密钥
- 跳板机和目标服务器都会做首次指纹确认，避免自动接受伪造主机
- 导入/导出使用用户自行设置的口令加密，导出文件不包含明文口令
