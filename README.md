# FoxShell

SSH 连接管理工具：多标签终端 · 分屏 · SFTP · 资源监控 · 批量执行 · 端口转发 · 跳板机。

## 下载

到 [Releases](https://github.com/The7wa/foxshell/releases) 下载压缩包，解压后运行 `FoxShell.exe` 即可，免安装。

## 功能

- **连接管理**：文件夹分组、搜索、克隆、导入/导出；密码 / 私钥登录；支持跳板机
- **终端**：多标签 + 左右/上下分屏 + 复制终端；背景/字体/光标样式自定义；主题一键切换；Ctrl+F 搜索；日志导出
- **SFTP**：浏览、上传、下载（支持文件夹）、重命名、删除，带进度条
- **资源监控**：CPU / 内存 / 网络 / 磁盘 / 负载 / 运行时长，实时刷新
- **批量执行**：勾选多台服务器，一条命令同步执行
- **端口转发**：本地端口 → 远程目标，一键启停

## 从源码运行

```bash
npm install
npm start
```

## 打包

```bash
npm run dist
```

## 说明

- 连接配置保存在本地 `%APPDATA%/foxshell/connections.json`，口令加密存储，不会上传
- 资源监控依赖 Linux 的 /proc，连接其他系统时监控栏提示不可用，终端与 SFTP 不受影响
